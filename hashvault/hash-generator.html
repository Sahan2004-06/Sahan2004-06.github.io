SHA-256 SECURE

256-bit output. The current industry standard — used in SSL/TLS, Bitcoin, and modern password storage. Resistant to known attacks.

MD5 LEGACY

128-bit output. Fast, but cryptographically broken since 2004. Still used for non-security checksums, but never for passwords.

One-Way Function KEY CONCEPT

Hashing is irreversible. You cannot derive the original input from a hash. This is what makes it safe for storing passwords.

Avalanche Effect KEY CONCEPT

Changing even one character in the input produces a completely different hash. Try hashing "hello" vs "Hello" to see it.
